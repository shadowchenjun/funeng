# 农业产业数据与供应链金融口径（首期）

## 本期交付边界

六页本地原型：全国产业总览、种植养殖、市场行情、冷链流通、产业风险、农业供应链金融。已有行情原型保留。首批只读采集器输出真实 JSON 快照，尚未安装生产定时任务、写入 Supabase 或发布 Vercel。

后端现有供应链金融模块含订单融资、应收账款、保险和信用评估表；其种子记录不能当作真实放款或风险数据。现有金额字段为 Float，后续金融统计接入前须迁移 Numeric/Decimal 并核对银行回执、主体权限、重复事件和历史数据。

## 首批可执行采集

cd backend
.venv/bin/python -m scripts.collect_industry_data --source all --output /tmp/funeng-industry.json

命令只查询固定的官方发布页，不自动推断“最新报告”，输出 `observations`、`sources`、`errors`。来源失败产生非零退出码，成功行保留，不补零或用演示数据代替。每次发布更换来源 URL 和报告周期，先验证再刷新。快照文件写入采用原子替换；没有 `--write-db` 参数。

## 统一记录

主键粒度：`source_id + metric + region + category + period_start + period_end + unit` 的散列；数值修订不改变主键。

必填：指标代码/中文名、地域、品类、统计起止时间、频率、原始 Decimal 字符串、原始单位、来源 URL、证据原文、度量类型。可选：来源报告的同比百分比、`qualifier`（精确/大于/大于等于/约）。

1 千公顷 = 1.5 万亩。单产公斤/公顷除以 15 为公斤/亩。原始单位与数值保留，转换属于展示层。全国公布总数优先于省份合计（四舍五入可有差异）。播种面积、果园年末面积、水域养殖面积分别保留，不能合成土地总面积。

## 金融公开数据：行业背景

| 指标 | 单位 / 属性 | 使用约束 |
|---|---|---|
| 涉农贷款余额 | 万亿元 / 时点存量 | 不等于农业供应链融资余额，不用作平台融资额 |
| 农村贷款、农户贷款、农业贷款余额 | 万亿元 / 时点存量 | 分类有重叠，分别比较，不画相加的堆叠图或占比饼图 |
| 贷款同比 | % / 来源已公布增长率 | 不能把报告余额自行比较得到的非可比增长称为官方同比；2024 年 6 月涉农统计地域口径调整须标注 |
| 农业保险保费 | 亿元 / 年内累计流量 | 保费不是保险金额、授信额或银行贷款 |
| 农业保险风险保障金额 | 万亿元 / 报告期保障规模 | 同一保单/主体可重复统计，不等于融资资产可用货值 |
| 农业保险赔款 | 亿元 / 年内累计流量 | 全国赔款不等于平台已理赔金额 |
| 中央农业保险保费补贴 | 亿元 / 年内财政支出 | 不能混同银行贷款或合计为金融支持总额 |

财政部首批报告对保费、保障和赔款使用“超”，快照分别标记 `gt`，不伪造成精确值或据此计算精确赔付率。公开全国统计不会随省份筛选伪造分省分摊。

## 平台供应链金融：后续真实业务接口

以下是目标指标，不是当前实测结果。未接入一律显示“待接入”，不能显示 0 或使用种子数据。

| 指标 | 建议定义 | 所需原始事实 |
|---|---|---|
| 申请融资金额 | 时间范围内有效申请金额，排除草稿、撤回、重复申请；融资方式单列 | application_id、tenant_id、申请提交时间、金额、状态、融资方式 |
| 审批金额 | 时间范围内正式审批通过金额 | 审批事件、审批额度、审批时间；不等同放款 |
| 放款金额 | 时间范围内银行实际成功到账本金，撤销/冲正按事件处理 | 唯一银行交易号、状态、金额、到账时间、冲正关系 |
| 融资本金余额 | 截止日各笔已到账本金扣除已入账本金偿还与本金冲正后的余额 | 放款与还本台账、截止时间、币种 |
| 融资企业数 | 选定周期内实际放款的授权企业按统一主体标识去重 | 企业统一标识、tenant_id、成功放款事件 |
| 加权融资年利率 | 按约定口径以本金/余额加权；只比较同币种和同利率口径 | 实际年利率、融资费用、权重、有效期 |
| 逾期本金及占比 | 截止日到期未还本金 / 同范围融资本金余额；余额为 0 时比例为空 | 合同还款计划、实际还本、展期批准、业务日历 |
| 应收账款未回款余额 | 经确权有效账款金额减已核销回款，剔除作废与重复发票 | 发票/债权唯一键、确权、回款、争议、到期日 |
| 仓单质押货值 | 已核验库存 × 对应规格估值价，按估值时间记录；不是授信额度 | 仓单唯一键、质押登记、库存核验、规格、估值、有效期 |
| 订单融资 | 按实际融资方式归类的申请/放款/余额 | 真实订单、合同、履约及结算、银行回执 |
| 风险状态 | 库存不符、重复质押疑点、逾期、保险到期、订单异常分别展示 | 可追溯核验事件；行业价格只作参考，不能生成银行信用评级 |

新增租户指标接口须鉴权、按主体授权，返回聚合值；不能公开借款人姓名、身份证、银行卡、银行征信、合同原文。统计访问不执行授信、放款、担保登记或调用银行交易接口。
