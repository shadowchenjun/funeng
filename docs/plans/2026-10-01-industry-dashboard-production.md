# Execution Plan: 产业大数据大屏接入正式平台

## Status: Complete
## Complexity: High
## Packages affected: backend, frontend, docs

## Goal

登录后的用户可从平台菜单和 `/industry-dashboard` 进入现有六页产业大屏。后端通过 postgres 读取 Supabase 已入库的真实数据，前端不使用 Supabase 密钥、不开放 Data API 权限。保留来源、统计期、金额精度、样本与缺失状态；显示实际入库时间和手动更新状态。完成测试、渲染验证、提交、main 发布及线上接口核验。

## Sprint Plan

### Sprint 1: 已授权的只读数据接口

- [x] 数据模型映射已有产业表，SQLite 测试兼容，不增加生产迁移。

- [x] main 发布及线上接口/页面验证。

## Decisions

| Decision | Rationale | Date |
|---|---|---|
| 保留用户已有六页原型设计 | 本次重点为接入，避免重建导致已确认布局和交互丢失 | 2026-10-01 |
| 后端统一读取已入库表 | 权限刚收回，浏览器只访问现有业务后端 | 2026-10-01 |
| 年度/季度数据和行情日期分别显示 | 数据已入库但无自动调度，不能暗示实时刷新 | 2026-10-01 |
| 公共产业统计和平台金融运营分开 | 银行回执等真实运营指标尚未接入，不伪造零或全国融资总量 | 2026-10-01 |

## Known risks

- 老原型包含固定时点/计数，接入时必须用返回数据替换或明确数据来源。
- 同一指标多期不能相加；价格趋势只使用已发布日期，不填补缺失。
- 浏览器渲染中嵌入数据须转义 HTML/script，来源 URL 仅允许 HTTP(S)。
- 后端发布先于前端验收；刷新请求有超时，认证失效按平台流程处理。
