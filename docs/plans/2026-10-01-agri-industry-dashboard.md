# 农业产业驾驶舱与供应链金融 Implementation Plan

**Goal:** 以真实公开资料交付六个可切换的产业大屏页面、可复用的首批采集代码和数据字典，作为生产接入的首期验收版本。

**Architecture:** 复用已有价格采集模块和原型，不修改商品、订单或生产数据库。产业指标按地域、品类、统计周期、单位和来源独立保存，金融金额使用 Decimal。本期静态快照用于审阅；后续持久化通过 FastAPI 读取 Supabase，公开统计和租户业务指标分别授权。

**Tech Stack:** Python、requests、BeautifulSoup、Decimal、JSON、HTML/CSS/JavaScript、SVG；后续生产沿用 Vue 3、FastAPI、PostgreSQL。

## Status: Review Ready（Sprint 1、2 本地成果已交付；Sprint 3 数据入库已完成，正式API/页面/调度待接入）
## Complexity: High
## Packages affected: backend（只读采集与测试）、docs（字典、快照、原型）

## 已确认的产品范围

1. 全国产业总览：产量、面积、价格样本、金融环境，分别标明统计期。
2. 种植养殖：31 省粮食面积、产量、单产；果园、茶园及经济作物展示已核实样本和补齐状态；水产全国统计。
3. 市场行情：保留已有行情页面及其筛选、搜索、导出。
4. 冷链流通：公开冷链基地、库容/处理能力资料；没有实际物流轨迹时不绘制业务流向。
5. 产业风险：质量抽检、受灾/绝收面积和农业气象来源；不把文字报告包装成实时监测。
6. 农业供应链金融：公开涉农信贷背景、农业保险与补贴；订单融资、仓单质押、应收账款融资的业务指标字典。

## 已明确的金融指标

| 层级 | 指标 | 取得方式 |
|---|---|---|
| 全国/省级背景 | 涉农贷款余额与同比、农户贷款、农业贷款 | 人民银行及官方转载、各省统计公报 |
| 风险保障 | 农业保险保费、保险金额、赔款、中央保费补贴 | 金融监管总局、财政部；区分上下限披露 |
| 平台业务 | 申请/审批/放款/余额、融资企业数、应收账款、仓单质押、还款和逾期本金 | 平台及银行授权回执，当前未实测接入 |
| 资产与履约 | 确权状态、仓单剩余货值、库存验证、订单履约、保险有效性 | 仓储/订单/结算和保险系统，当前未实测接入 |

## Known risks

- 涉农贷款包括多种融资，不等于农业供应链金融；农村、农户、农业贷款分类不可简单相加。
- 年报与季度数据不能伪造连续月度趋势。公开宏观资料不代替客户征信和银行授信。
- 部分官方表格是图片/PDF，需要复核提取；无数据保留 null 或待接入状态。
- 官方页面许可与自动采集可用性需逐来源确认，当前低频技术验证不证明生产长期稳定。
